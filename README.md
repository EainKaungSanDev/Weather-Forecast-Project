# 🌤️ Weather Forecast

A responsive weather forecast web app built with React, TypeScript, Vite, and Visual Crossing Weather API.

## 🔗 Live Demo
- 🌐 [View Live App](https://weather-forecast-lac-beta.vercel.app)

## ✨ Features

- 🔎 Search weather by city name
- 📍 Search weather using latitude and longitude
- 🗺️ Interactive map with OpenStreetMap
- 📌 Click on the map to select coordinates
- 🌡️ Current weather information
- 🕐 Hourly weather forecast
- 📅 3-day weather forecast
- 🌤️ Weather condition icons
- 🌡️ Metric / US unit switch
- 🔄 Refresh weather data
- ⏳ Loading animation
- ❌ Error handling
- 📱 Responsive design
- 🔐 API key protected with Vercel Environment Variables
